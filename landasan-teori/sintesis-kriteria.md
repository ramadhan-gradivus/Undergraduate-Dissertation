# Sintesis: Empat Kriteria, 18 Variabel Awal

Kajian teori lokasi fasilitas umum, teori lokasi bandar udara, dan PM 20/2014 disintesis menjadi **empat kriteria** dengan **18 variabel awal**.

| Kriteria | Variabel awal |
| --- | --- |
| **Pengembangan wilayah** | Kesesuaian dengan tata ruang; kesesuaian dengan tataran transportasi; kebijakan daerah rawan bencana, terisolir, perbatasan; kesesuaian dengan rencana induk nasional bandar udara |
| **Teknis pembangunan** | Topografi; kondisi dan kelandaian permukaan tanah; aliran air / drainase; meteorologi dan geofisika; daya dukung; struktur tanah; infrastruktur; jaringan utilitas |
| **Lingkungan** | Lingkungan alam; peruntukan lahan; penguasaan lahan |
| **Sosial** | Relokasi penduduk; keserasian dengan budaya setempat; kependudukan / lapangan kerja |

{% hint style="info" %}
Daftar ini masih berbasis literatur. Apakah setiap variabel benar-benar relevan untuk **Lamongan** dikonfirmasi oleh pakar pada tahap Delphi. Hasilnya ada di [Hasil Delphi](../hasil/delphi.md).
{% endhint %}
