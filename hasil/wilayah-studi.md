# Gambaran Wilayah Studi

## Administrasi

Kabupaten Lamongan memiliki **27 kecamatan**, **462 desa**, dan **12 kelurahan** pada wilayah seluas **181.280 ha**.

## Kondisi fisik dasar

| Aspek | Kondisi |
| --- | --- |
| Topografi | Ketinggian maksimum 194 mdpl |
| Kemiringan | 0-2% dominan di utara (sekitar Sungai Bengawan Solo), beragam hingga 15%; selatan bergelombang hingga 63% |
| Jenis tanah | Aluvial, regosol, grumosol, mediteran |
| Penggunaan lahan | Didominasi pertanian (sawah irigasi 41,55%) |
| Curah hujan | 1.000 sampai 2.000 mm per tahun |
| Suhu | Tertinggi 33,40 °C (September), terendah 28,38 °C (April) |
| Kelembapan | Tertinggi 86% (Juni) |
