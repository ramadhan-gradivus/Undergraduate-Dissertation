# Lokasi Terpilih: Solokuro-Paciran

## Penyaringan kebutuhan lahan

Lahan bandara yang direncanakan seluas **±63 ha**, mengacu pada luas Bandara Internasional Juanda. Bentuknya harus memuat **runway 3.000 m** dengan asumsi melayani pesawat Boeing 737.

| Komponen | Luas (ha) |
| --- | --- |
| Runway | 13,50 |
| Apron | 9,48 |
| Peralatan navigasi | 37,47 |
| Terminal | 0,12 |
| Parkir pengunjung | 2,43 |
| **Total** | **63,00** |

## Hasil

{% hint style="success" %}
Lahan yang sesuai berada **di antara Kecamatan Solokuro dan Kecamatan Paciran**.
{% endhint %}

## Kawasan Keselamatan Operasi Penerbangan (KKOP)

Karena studi hanya menetapkan lokasi, KKOP ditarik **sebagian** dari garis terluar wilayah terpilih (ICAO, 2013):

| Zona | Batas |
| --- | --- |
| Permukaan horizontal dalam (*inner horizontal*) | Radius 4.000 m dari titik tengah tiap ujung permukaan utama |
| Permukaan kerucut (*conical*) | Transisi pada 4.000 sampai 6.000 m |
| Permukaan horizontal luar (*outer horizontal*) | Radius 6.000 sampai 15.000 m |
