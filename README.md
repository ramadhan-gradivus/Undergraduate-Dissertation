# Penentuan Lokasi Bandar Udara di Kabupaten Lamongan

> Di mana bandar udara baru Kabupaten Lamongan sebaiknya dibangun? Penelitian ini menjawabnya dengan tiga alat analisis: **Delphi**, **AHP**, dan **weighted overlay** di ArcGIS.

{% hint style="success" %}
**Jawaban singkat:** lahan yang paling sesuai berada di antara **Kecamatan Solokuro dan Kecamatan Paciran**, di pesisir utara Kabupaten Lamongan.
{% endhint %}

## Penelitian dalam angka

| Angka | Keterangan |
| --- | --- |
| **181.280 ha** | Luas wilayah studi (27 kecamatan) |
| **5 responden** | Stakeholder dari pemerintah, operator bandara, dan praktisi |
| **18 → 14** | Variabel awal dari kajian pustaka, lalu terkonfirmasi pakar lewat Delphi |
| **4 kriteria** | Pengembangan wilayah, teknis pembangunan, lingkungan, sosial |
| **37%** | Bobot kriteria teknis pembangunan, yang tertinggi di antara keempatnya |
| **0,228 – 0,970** | Rentang skor kesesuaian lahan hasil overlay |
| **±63 ha** | Kebutuhan lahan bandara yang menjadi filter akhir |
